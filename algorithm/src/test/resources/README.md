# Test images for `algorithm`

- Put your own input image as `input.png` in this directory.
- If `input.png` is missing, the test `ContrastStretchingImageIoTest` will auto-generate `generated_input.png`.
- Output image is written to `build/test-output/contrast_output.png` (relative to the `algorithm` module directory).
- Metrics report (before/after: min/max/range/mean/std + luma stats) is written to `build/test-output/contrast_metrics.txt`.
